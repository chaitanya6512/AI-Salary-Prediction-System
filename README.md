# 📌 Project Overview

This project predicts the annual salary of AI, Machine Learning, and Data Science professionals using Machine Learning.

The application is built with **Python**, **XGBoost**, and **Streamlit**, allowing users to enter job information and instantly receive a salary prediction.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/AI-Salary-Prediction.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
